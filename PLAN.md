# Новая платформа АИС автовокзалов — план

> Разбор легаси-системы (архитектура, поток покупки, процедуры, подводные камни): [docs/LEGACY.md](docs/LEGACY.md)

## Цель
Перевести три легаси-компонента на современный стек, сохранив работу с вендорными
базами продаж (Firebird 2.5, менять нельзя).

## Компоненты (что переводим)
| Легаси | Что это | Стек сейчас | Куда |
|--------|---------|-------------|------|
| `avtovokzal57` | Публичный сайт (расписание, продажа билетов) | процедурный PHP | Nuxt (фронт) + Laravel (API) |
| `ais` | Внутренняя АИС (отчёты, админка, бухгалтерия) | процедурный PHP | Laravel + Nuxt (SPA v2 — уже начата) |
| `ais/api` | API продаж, к нему обращается сайт | процедурный PHP | Laravel (сервисный слой к Firebird) |

## Базы данных
- **Вендорные Firebird 2.5** (продажи, `$AWT`/`$ALT_IP` в `ais/admin/inc/config.php`) —
  **не трогаем**, структура вендорная. Доступ по сети (`10.1.102.x/3050` и др.).
  Платформа читает их через `pdo_firebird`.
- **Наши базы** `site` и `ais` (сейчас Firebird) — **переводим в PostgreSQL**,
  структуру проектируем заново (Laravel-миграции).

## Целевой стек
- **PHP 8.5** + **Laravel 13** — бэкенд/API, сервисный слой к Firebird и Postgres.
- **Nuxt** (Node 24) — фронтенд (публичный сайт + внутренние интерфейсы).
- **PostgreSQL 17** — наши данные.
- **Docker Compose** — dev сейчас, prod позже (bind mounts, без именованных томов).
- Firebird-клиент (`libfbclient` + `pdo_firebird`) в PHP-образе для доступа к продажам.

## Структура репозитория
```
avtovokzal_new_platform/
  docker-compose.yml            # базовое описание сервисов (dev)
  docker-compose.prod.yml       # оверрайд для прода (позже)
  .env                          # переменные (не в git)
  .env.example
  docker/
    php/Dockerfile  php/php.ini
    nginx/default.conf
  backend/                      # Laravel 13 (bind mount)
  frontend/                     # Nuxt (bind mount)
  data/postgres/                # данные Postgres (bind mount, не в git)
```

## Сервисы Compose
- **db** — postgres:17, данные в `./data/postgres` (bind).
- **app** — php:8.5-fpm + расширения (`pdo_pgsql`, `pdo_firebird`, intl, mbstring, …) + composer.
- **web** — nginx, отдаёт `backend/public`, проксирует на app:9000.
- **frontend** — node:24, Nuxt dev-сервер.

## Этапы (после поднятия окружения)
1. **Окружение** — docker compose, скелеты Laravel + Nuxt, Postgres, доступ к Firebird. ✅
2. **Доступ к Firebird** — connection-менеджер к серверам продаж из `$AWT`, сервис-обёртки. ✅ (`sales-api/app/Services/Buster/*`)
3. **Схема Postgres** — таблицы `sales` (журнал/резервы/продажи/возвраты) и `orders`. ✅ (частично: USERS/ЛК — позже)
4. **API продаж** — `sales-api/` (Laravel 13, порт :8085): рейсы, места, резерв, продажа, возврат + журнал. ✅
5. **API avtovokzal57** — `backend/` (порт :8080): заказы, оплата Сбербанк (SDK), payconfirm, очередь чеков/писем. ✅ (обработчик очереди пока не запущен)
6. **Сайт** — `frontend/` Nuxt + Nuxt UI (порт :3000): поиск, рейсы, пассажиры, оплата, успех. ✅ (покупка,
   включая валидацию документов по правилам станции, справочник гражданств, ФИО/Ё→Е);
   расписание/ЛК/возврат — в работе
7. **АИС** — отчёты (уже есть SPA v2 для agents) переводятся на Laravel API + Nuxt.
8. **Прод** — `docker-compose.prod.yml`, деплой на Linux-сервер.
