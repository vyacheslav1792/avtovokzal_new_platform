# Тестирование оплаты и билетов

## Тестовая карта Сбера

Реквизиты, предоставленные для тестирования проекта:

| Поле | Значение |
|---|---|
| Номер карты | `6390 0200 0000 000003` |
| Срок действия (год/месяц) | `2034/12` |
| Проверочный код на обратной стороне | `123` (необязательный параметр) |
| 3-D Secure | `veres=y, pares=a` |
| Проверочный код 3-D Secure | `12345678` |

Тестовый шлюз: `https://3dsec.sberbank.ru`.

## Скачивание билетов в PDF

Кнопки скачивания в личном кабинете и после оплаты формируют ссылку
`<NUXT_PUBLIC_API_BASE>/api/v1/orders/<order_id>/pdf`.
В продакшене `NUXT_PUBLIC_API_BASE=https://site.orelavtotrans.ru` задаётся
в `docker-compose.prod.yml`. Этот адрес доступен браузеру покупателя.
После изменения runtime-переменной нужно пересоздать контейнер `frontend`:

```bash
docker compose up -d --no-deps frontend
```

Для рендера печатной формы Gotenberg использует внутренний адрес
`http://frontend:3000/print/<order_id>` (`PRINT_BASE_URL` в backend).
